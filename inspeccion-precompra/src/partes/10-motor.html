Vano motor y arranque en frío

Con el motor frío y apagado

Temperatura real al llegar :: Mano sobre el capó, el múltiple de escape (con cuidado) y la manguera superior del radiador. :: Fríos. :: Tibios o calientes: lo encendieron antes. Preguntar por qué; se informa. :: r Limpieza general del vano :: Observar si está sucio "normal", impecable o recién lavado/abrillantado. :: Polvo uniforme acorde al uso. :: Recién lavado o con brillo de silicona: puede ocultar fugas. Revisar con más detalle. :: y Fugas visibles :: Linterna en tapa de válvulas, culata, cárter, bomba de agua, mangueras, radiador, dirección y caja. :: Seco o con humedad leve antigua. :: Aceite goteando, costras de refrigerante (blancas, verdes o rosadas), humedad fresca. :: r Aceite: nivel y estado :: Sacar varilla, limpiar, volver a meter, leer. Gota en paño blanco. Oler. :: Entre MIN y MAX; ámbar a marrón oscuro; sin partículas. :: Bajo el mínimo (consume o fuga), sobre el máximo (puede ocultar dilución), olor a combustible, partículas metálicas, aspecto lechoso. :: r Tapa de aceite (interior) :: Sacar la tapa y mirar con linterna el interior y la tapa. :: Limpia o con película de aceite. :: Pasta blanca/café tipo "mayonesa" (mezcla con refrigerante: posible junta de culata), lodo negro espeso (mantenciones descuidadas). :: r Refrigerante :: SOLO en frío: abrir depósito, mirar nivel, color y superficie. :: Nivel entre marcas, color limpio (verde, rosado, naranja, azul según marca), sin capa aceitosa. :: Aceite flotando o color café (junta de culata, enfriador de aceite), solo agua, óxido, nivel muy bajo. :: k Líquido de frenos :: Nivel en el depósito y color; tester de humedad si se tiene. :: Entre MIN y MAX, ámbar claro, humedad < 3 %. :: Oscuro/negro (no se ha cambiado en años), nivel muy bajo (pastillas gastadas o fuga). :: y Dirección hidráulica (si aplica) :: Nivel y color del depósito. :: Nivel correcto, rojo o claro. :: Bajo, oscuro, espumoso o con olor a quemado. :: y Correas :: Inspeccionar correa auxiliar por dentro (doblarla un poco): grietas, deshilachado, brillo. Preguntar por la de distribución. :: Flexible y sin grietas. :: Grietas transversales, brillo (patina), tensor que vibra. Distribución sin respaldo de cambio: presupuesto obligatorio. :: y Mangueras :: Apretar (en frío) las mangueras de radiador y calefacción. :: Firmes y elásticas. :: Duras, agrietadas, hinchadas o con abrazaderas no originales. :: y Batería :: Fecha de fabricación, bornes, fijación; medir voltaje en reposo. :: 12,5–12,7 V; bornes limpios; menos de 4–5 años. :: < 12,2 V, bornes sulfatados, batería sin fijación, hinchada. :: y Cableado y fusibles :: Buscar empalmes con cinta, cables agregados (alarmas, audio), fusibles puenteados o de amperaje mayor. :: Arnés de fábrica intacto. :: Empalmes caseros, cables pelados, fusibles alterados: riesgo de incendio y fallas eléctricas. :: r Filtro de aire :: Abrir la caja si es de clips (sin herramientas). :: Filtro razonablemente limpio. :: Muy sucio o con aceite en la caja (exceso de gases del cárter / turbo). :: y Señales de reparación del motor :: Juntas con silicona desbordada, tornillos de culata con marcas, piezas muy nuevas en motor viejo, pintura fresca en el bloque. :: Sin intervenciones mayores o con factura. :: Culata o motor abierto sin respaldo: preguntar por qué. Motor "recién hecho" sin factura. :: r Soportes de motor :: Mirar gomas de los soportes (grietas, separación). :: Gomas íntegras. :: Gomas rotas o separadas (vibración, golpes al cambiar de marcha). :: y

Arranque en frío ayudante en el auto, inspector en el escape y luego en el capó

Tiempo de arranque :: Contar segundos de giro del motor de partida. :: Arranca en 1–2 s (diésel: tras apagarse el testigo de precalentamiento). :: Gira lento (batería o motor de partida), varios intentos o arranca y se apaga. :: r Ruidos en los primeros segundos :: Escuchar con el capó abierto los primeros 5 s. :: Ruido parejo; leve tic de inyectores es normal. :: Cascabeleo metálico 1–3 s (cadena de distribución o tensor), golpeteo profundo (bielas), chirrido (correa). :: r Humo del escape :: Mirar el escape al arrancar y tras 1 min; acelerar suave a 2.500 rpm (Fig. 10.2). :: Vapor blanco tenue que desaparece en frío (condensación). :: Humo azul, negro persistente o blanco denso y dulce. :: r Ralentí :: Observar tacómetro y escuchar durante 2–3 min. :: Estable; baja las RPM al calentar. :: Oscila, vibra el auto, se apaga, "falla" rítmica (bujía, bobina, inyector). :: r Prueba de gases del cárter (blow-by) :: Con motor en ralentí, retirar la tapa de aceite unos segundos (o levantar la varilla). :: Leve vapor o ligera pulsación. :: Humo abundante con presión, aceite que salpica, varilla que se levanta: desgaste de anillos/pistones. :: k Depósito de refrigerante en marcha :: Mirar el depósito (sin abrir) con el motor ya tibio. :: Superficie tranquila. :: Burbujas constantes: gases de combustión en el refrigerante (junta de culata). :: k Movimiento del motor :: Con freno pisado a fondo, pasar de P/N a D y a R (o soltar embrague suave) mientras el ayudante observa el motor. :: Leve movimiento. :: El motor se sacude fuerte o golpea: soportes rotos. :: y Electroventiladores :: Al llegar a temperatura (o con A/C encendido) deben activarse. :: Se activan y paran. :: No se activan: riesgo de sobrecalentamiento en tráfico. :: r Voltaje de carga :: Multímetro en bornes con motor en marcha y consumos encendidos. :: 13,8–14,7 V. :: < 13,2 V (alternador débil) o > 15 V (regulador dañado). :: r
