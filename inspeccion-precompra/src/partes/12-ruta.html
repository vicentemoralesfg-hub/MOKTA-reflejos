Fase 7 · Dinámica

Prueba de ruta

Aquí aparecen la caja, la suspensión, los frenos y los ruidos que en detenido no existen. Radio apagada, ventanas cerradas y luego abiertas.

20–30 min · 10–15 kmVendedor a bordo

Motor y respuesta

Aceleración progresiva :: En 2ª y 3ª, acelerar desde bajas RPM hasta 4.000 rpm (motor caliente). :: Sube suave y lineal, sin tirones. :: Tirones, falla, "hueco" de potencia, cascabeleo (detonación). :: r Turbo (si aplica) :: Acelerar a fondo brevemente en 3ª desde 1.500 rpm. :: Empuje claro desde ≈ 1.800–2.000 rpm; silbido leve. :: Sin empuje, silbido tipo sirena, humo azul al soltar, modo de emergencia. :: r Temperatura en marcha y en tráfico :: Vigilar indicador durante toda la ruta y en el tramo 8. :: Estable al centro. :: Sube en tráfico (ventilador/radiador) o en subida. :: k Retención de motor :: Soltar el acelerador a 60 km/h en 3ª/4ª. :: Retiene sin ruidos. :: Golpe en la transmisión al soltar/acelerar (soportes, crucetas, holguras). :: y

Transmisión manual

Embrague :: Punto de enganche y recorrido del pedal. :: Engancha a media altura, suave. :: Engancha muy arriba (desgastado), vibra al arrancar, pedal duro. :: y Patinaje :: En 4ª a 50 km/h, acelerar a fondo. :: RPM y velocidad suben juntas. :: Suben las RPM y no la velocidad: embrague patina. :: r Cambios :: Pasar todas las marchas subiendo y bajando, también rápido. :: Entran sin raspar. :: Raspa (sincronizadores), se sale la marcha, palanca con mucho juego. :: r Ruidos de caja :: Escuchar en cada marcha y en neutro con embrague suelto. :: Silencioso. :: Zumbido en una marcha; ruido en neutro que desaparece al pisar (rodamiento). :: r Volante bimasa (diésel/turbo) :: Escuchar al apagar el motor y en ralentí. :: Sin golpeteo. :: Traqueteo metálico al apagar o en ralentí: bimasa gastado (costoso). :: r

Transmisión automática / CVT / doble embrague

Enganche P→R→D :: Con freno pisado, cambiar posiciones y contar el tiempo de enganche. :: Engancha en < 1 s con leve toque. :: Demora de 2 s o más, golpe fuerte. :: r Cambios en aceleración :: Acelerar suave y luego firme. :: Cambios suaves y oportunos. :: Patina (sube RPM sin avanzar), golpea, cambia tarde, se queda en una marcha (modo emergencia). :: k Cambios descendentes :: Frenar progresivamente hasta detenerse. :: Imperceptibles. :: Golpe al bajar a 2ª o 1ª. :: r CVT :: Acelerar suave y sostenido. :: Aceleración lineal, sin zumbidos. :: Zumbido/silbido creciente, tirones, vibración al arrancar: CVT con desgaste (muy costosa). :: k Doble embrague (DSG, etc.) :: Arranques desde detenido en plano y subida, maniobras lentas. :: Arranque suave. :: Vibración al arrancar, golpes en 1ª-2ª, demora o mensaje de caja: mecatrónica o embragues. :: r

Dirección, frenos y suspensión

Centrado de dirección :: En recta plana, soltar suavemente el volante unos segundos. :: Va derecho y el volante queda centrado. :: Se va hacia un lado o el volante queda chueco: alineación, neumáticos o chasis. :: y Juego y ruidos de dirección :: Movimientos cortos del volante en recta; giro tope a tope en maniobra. :: Respuesta precisa; sin ruidos. :: Juego excesivo, golpeteo (terminales, cremallera), chillido (bomba hidráulica). :: r Homocinéticas :: Giro cerrado en ambos sentidos acelerando (tramo 1). :: Silencioso. :: "Clac-clac" rítmico al girar acelerando: homocinética exterior. :: r Frenada normal :: Frenadas progresivas. :: Recta, pedal firme y progresivo. :: Se desvía, pedal esponjoso o que se va al fondo, chirrido. :: r Frenada firme (tramo 6) :: Sin tráfico detrás, desde 60–80 km/h frenar fuerte (sin bloquear). :: Recta, ABS solo si se fuerza, sin vibración. :: Vibra el volante o pedal (discos alabeados), tira hacia un lado (cáliper), ABS que actúa sin razón. :: r Freno de mano / estacionamiento :: Detenerse en pendiente y aplicar. :: Sostiene el auto. :: No sostiene; freno eléctrico con error. :: y Resaltos :: Pasar a 20–30 km/h (tramo 3), ventanas abiertas. :: Absorbe sin golpes secos. :: Golpe metálico, crujido, rebote excesivo. :: y Estabilidad en curva y a velocidad :: Curvas y rotonda a velocidad moderada; tramo 5 a 80–100 km/h. :: Estable, sin balanceo exagerado ni flotación. :: Flota (amortiguadores), se mueve en línea recta, vibración a cierta velocidad (balanceo, llanta doblada). :: y Ruido de rodamientos :: En tramo 5, escuchar zumbido; cambiar de carril suavemente a izquierda/derecha. :: Silencioso. :: Zumbido que sube con la velocidad y cambia al cargar en curva: rodamiento de rueda. :: y
