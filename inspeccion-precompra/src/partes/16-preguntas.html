Entrevista

Banco de preguntas clave

Lo que el vendedor dice, cómo lo dice y lo que calla, es parte de la inspección. Cada respuesta se anota textual y se contrasta con la evidencia.

Anotar textual

Preguntas abiertas

"Cuénteme la historia del auto" rinde más que "¿ha chocado?". Las cerradas invitan a un "no" automático.

Repetir en otro momento

Haz la misma pregunta clave al inicio y después de la ruta. Las versiones inventadas cambian.

Silencio táctico

Tras la respuesta, espera 3 segundos sin hablar. Muchas veces el vendedor agrega el dato importante.

Evidencia antes que juicio

Si algo no calza, no acuses: "Veo que este panel tiene otra medición, ¿sabe qué le pasó?".

A · Llamada filtro antes de agendar · descarta autos sin salir

¿El auto está a su nombre? ¿Usted estará presente con su cédula? :: Solo el titular (o apoderado con poder notarial) puede vender. :: "Está a nombre de mi papá/señora/empresa, pero yo lo vendo". ¿Por qué lo vende? :: Revela urgencia, problemas o cambio de vida. Se contrasta después con lo encontrado. :: Respuesta evasiva, contradicción o "porque compré otro" en un auto recién adquirido. ¿Hace cuánto lo tiene y cuántos dueños ha tenido? :: Dueño de largo plazo suele conocer la historia completa. :: Lo tiene hace pocas semanas o no sabe nada de la historia. ¿Tiene prenda, crédito vigente, multas o TAG impagos? :: Impedimentos o costos para la transferencia. :: "Sí, pero lo pago con lo que usted me pague" (riesgo alto). ¿Cuál es el kilometraje exacto y cómo lo respalda? :: Prepara la comparación con timbres, historial y desgaste. :: Km redondo "más o menos", sin respaldos. ¿Dónde se hicieron las mantenciones? ¿Tiene boletas o libro timbrado? :: La documentación vale tanto como el auto. :: "Las hacía yo" o "en un taller de un amigo, sin boletas". ¿Ha tenido choques, aunque sean menores, o reparaciones de pintura? :: Prepara la lectura del medidor de pintura. :: "Nunca, ni una raya" (casi nunca es cierto en autos de más de 3 años). ¿Tiene algún testigo encendido en el tablero o alguna falla conocida? :: Primer filtro mecánico. :: "Es solo un sensor", "se apaga solo", "no es nada". ¿Acepta revisión con escáner, revisión de bajos y prueba de ruta de 20–30 min? :: Sin esto no hay dictamen. :: Se niega o pone condiciones extrañas. ¿Puede no encender el auto desde la noche anterior? :: Necesitamos arranque en frío. :: "Lo tengo que mover igual", insiste en tenerlo "calentito".

B · En terreno con el vendedor, durante la inspección

Cuénteme la historia del auto desde que lo compró. :: Pregunta abierta: revela uso, viajes, incidentes y cuidado. :: Relato muy corto, contradictorio con el CAV o con el desgaste. ¿Qué uso le daba? ¿Ciudad, carretera, trabajo, aplicaciones de transporte? :: Define desgaste esperado (embrague, DPF, suspensión). :: Uso de app o comercial no declarado antes. ¿Quién lo manejaba normalmente? :: Varios conductores o conductores jóvenes implican más desgaste. :: "Lo usaba toda la familia" + desgaste fuerte. ¿Cuándo y a qué km se cambió la correa o cadena de distribución? :: Reparación costosa; si no hay respaldo, se presupuesta. :: "Creo que se cambió" sin boleta, en auto sobre el intervalo. ¿Se ha cambiado embrague, frenos, amortiguadores, neumáticos o batería? ¿Cuándo? :: Cruza con desgaste observado y con el km. :: Embrague cambiado en auto de "pocos km" (contradicción). ¿Qué piezas fueron pintadas y por qué? :: Se contrasta con las mediciones del medidor. :: Niega pinturas que el medidor demuestra. ¿El auto ha usado alguna vez el seguro? ¿Por qué? :: Siniestros declarados aparecen en informes de historial. :: Niega siniestros que figuran en el historial. ¿Alguna vez estuvo en una inundación, aluvión o lluvia fuerte estacionado en zona baja? :: Prepara la búsqueda de señales de agua. :: Duda, cambia de tema o "solo un poco de agua". ¿Remolcó carro o casa rodante? ¿Llevó carga pesada? :: Sobreexigencia de embrague, caja, frenos y suspensión. :: Sí y frecuentemente, sin mantención reforzada. ¿Tiene modificaciones (chip, escape, suspensión, luces, GNC)? ¿Conserva las piezas originales? :: Riesgo en revisión técnica, seguro y durabilidad. :: Modificaciones no declaradas que aparecen en la inspección. ¿Tiene segunda llave, manuales y llave de pernos de seguridad? :: Costos de reposición. :: "La segunda llave se perdió" en un auto recién adquirido. ¿Se le hizo algún recall o campaña de servicio? :: Recalls de seguridad pendientes. :: No sabe o "no era necesario". ¿Cuál es el próximo gasto que usted sabe que viene? :: Pregunta que obliga a pensar; muchos vendedores honestos lo dicen. :: "Ninguno" en un auto con neumáticos, frenos o distribución vencidos. Si usted se quedara con el auto, ¿qué le arreglaría primero? :: Pregunta indirecta que revela fallas conocidas. :: Respuesta que coincide con una falla que negó antes. ¿Por qué encendió el auto antes de que llegáramos? (si estaba tibio) :: El arranque en frío era requisito. :: Excusa poco creíble; insistir en una segunda visita en frío. ¿Este testigo / ruido / medición desde cuándo está así? :: Cualquier hallazgo se consulta con neutralidad. :: "Recién apareció", "eso es normal en este modelo" sin respaldo.

C · Automotoras, consignación y empresas

¿De dónde viene este auto (parte de pago, remate, leasing, importación)? :: Origen define riesgos: remate de aseguradora o flota. :: "No sabemos" o se niega a mostrar el CAV. ¿El auto es de la automotora o está en consignación? ¿Quién es el titular? :: En consignación el vendedor legal es un tercero. :: El titular no aparece ni hay mandato escrito. ¿Qué garantía ofrecen, por cuánto tiempo y qué cubre exactamente? Por escrito. :: La Ley del Consumidor aplica a proveedores; la garantía debe constar por escrito. :: "Garantía de palabra" o garantía que excluye motor y caja. ¿Qué incluye el precio? ¿Hay gastos de transferencia, administrativos o de preparación aparte? :: Evitar sorpresas en el valor final. :: Cargos agregados al cierre que no estaban en el aviso. ¿Qué revisión hicieron ustedes y qué repararon? ¿Tienen las boletas? :: Muchas automotoras "preparan" el auto: pintura, pulido, borrado de códigos. :: "Lo revisamos completo" sin ningún documento. Si financian: ¿cuál es la tasa, el CAE y el costo total del crédito? :: El financiamiento puede encarecer mucho la compra. :: Solo informan la cuota mensual.
