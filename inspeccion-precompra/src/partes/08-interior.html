Referencia de uso

Uso particular en Chile: 12.000–20.000 km/año. Menos de 8.000 km/año es posible (segundo auto, adulto mayor) pero exige respaldo (timbres, revisiones técnicas). Más de 30.000 km/año sugiere uso comercial (aplicación de transporte, taxi, ventas en terreno). Un interior "de 200.000 km" con odómetro de 70.000 = sospecha de kilometraje adulterado (ver cap. 15).

Olores, humedad e inundación

Primer olor al abrir :: Abrir la puerta del conductor apenas llegas, antes de ventilar. :: Olor neutro. :: Humedad/moho (filtración o inundación), tabaco (difícil de eliminar), ambientador muy intenso (intenta tapar algo), olor a combustible o anticongelante dulce (fuga de calefactor). :: y Alfombras y piso :: Presionar con la mano en zonas bajas (pies delanteros y traseros, maleta). Levantar una esquina si se puede. :: Secas. :: Húmedas, con barro, arena o línea de agua en la espuma. :: r Rieles y pernos de asientos :: Linterna bajo los asientos delanteros. :: Metal limpio o con leve suciedad. :: Óxido en rieles, pernos o resortes: el agua llegó al piso. :: k Cinturones de seguridad :: Desenrollar completamente cada cinturón. Revisar marcas, olor y que se retraiga y bloquee con un tirón. :: Limpios, retraen rápido, bloquean. :: Línea de barro o manchas en la parte que nunca sale; no bloquean; fecha de etiqueta distinta (pretensores reemplazados tras choque). :: r Bajo el tablero y conectores :: Linterna bajo el tablero (lado conductor) y caja de fusibles interior. :: Cables y conectores limpios. :: Corrosión verde/blanca en conectores, barro seco, cables empalmados. :: k Tapiz del techo y pilares :: Manchas, arrugas, tapiz caído o con marcas de desmontaje. :: Uniforme y firme. :: Manchas de agua (techo solar, parabrisas mal sellado) o tapiz reinstalado (airbags de cortina activados o techo reparado). :: y

Confort y electrónica probar todo, sin excepción

Aire acondicionado :: Motor en marcha, A/C al máximo, recirculación, 5 min. Medir temperatura en la salida central con termómetro IR. :: Salida ≤ 8 °C; compresor engancha sin golpes; sin olor. :: Sale tibio, el compresor se activa y desactiva seguido (falta gas o fuga), ruido de compresor, olor a humedad. :: r Calefacción :: Con motor tibio, calefacción al máximo en todas las salidas. :: Aire caliente en 3–5 min. :: No calienta (termostato o calefactor tapado), olor dulce y vidrios empañados (fuga del radiador de calefacción). :: y Ventilador y distribución :: Todas las velocidades y todas las salidas (pies, frente, parabrisas). :: Todas funcionan. :: Velocidades faltantes (resistencia), aire que no cambia de salida (actuador). :: y Desempañador trasero y espejos :: Activar y tocar la luneta a los 3–5 min. :: Calienta parejo. :: Líneas cortadas. :: y Alzavidrios y cierre centralizado :: Cada vidrio desde su botón y desde el conductor; función un toque y antipinzamiento; cierre con mando y botón. :: Todo responde. :: Motores lentos, ruidos, puertas que no traban. :: y Asientos y volante eléctricos :: Todas las direcciones, memoria, calefacción/ventilación si tiene; ajuste de volante. :: Funcionan sin ruidos. :: Motores trabados, calefacción que no responde. :: y Multimedia y conectividad :: Radio, Bluetooth (conectar un celular), USB, Android Auto/CarPlay, parlantes (balance a cada uno), navegación. :: Todo funciona, pantalla sin píxeles muertos. :: Pantalla delaminada o táctil sin respuesta; parlantes rotos; radio aftermarket en auto que trae de serie (robo). :: y Cámara y sensores de estacionamiento :: Retroceso con obstáculo; imagen nítida y líneas guía. :: Funcionan correctamente. :: Sensor que no pita o pita siempre (pintado o dañado tras choque). :: y Asistencias de manejo (ADAS) :: Control crucero, crucero adaptativo, alerta de punto ciego, mantención de carril (en la prueba de ruta). :: Disponibles y sin mensajes de error. :: "Sistema no disponible" permanente: radar o cámara desalineados tras choque o parabrisas cambiado sin calibrar. :: r Bocina, luces interiores y enchufes :: Bocina, luces de lectura, guantera, maleta, tomas 12 V/USB. :: Funcionan. :: Fallas menores. :: y Cerraduras de seguridad de niños y guantera :: Probar en puertas traseras. :: Funcionan. :: Trabadas. :: y
