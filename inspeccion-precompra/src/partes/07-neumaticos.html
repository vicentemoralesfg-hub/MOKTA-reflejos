Neumáticos, llantas y frenos

El desgaste de los neumáticos es el "historial clínico" de la suspensión, la alineación y el estilo de manejo del dueño anterior.

Neumáticos

Medida y especificación :: Comparar medida, índice de carga y velocidad con la etiqueta del pilar B o tapa de combustible. :: Medida original o equivalente homologada. :: Medida distinta (afecta velocímetro, ABS/ESP, consumo); llantas y neumáticos de "tuning". :: y Coherencia por eje :: Misma marca, modelo y desgaste en cada eje (en 4x4 y AWD: idealmente las 4 iguales). :: Pares iguales por eje. :: Neumáticos distintos en un eje; en AWD/4x4, diferencias de desgaste dañan diferenciales y caja de transferencia. :: y Profundidad de surco :: Profundímetro en 3 puntos por rueda; anotar en hoja de campo. :: > 4 mm parejo. :: < 3 mm: presupuesto inmediato; < 1,6 mm: ilegal. :: y Patrón de desgaste :: Comparar con Fig. 7.1; pasar la mano por la banda. :: Desgaste parejo en todo el ancho. :: Desgaste en un borde, serrucho o copas: alineación, suspensión o amortiguadores (ver cap. 11 y 12). :: r Edad (DOT) :: Leer fecha en las 5 ruedas. :: Menos de 5 años. :: Más de 6 años: goma endurecida, recomendar cambio aunque tengan surco. Más de 10 años: STOP de seguridad hasta reemplazarlos. :: y Flancos :: Revisar ambos flancos con linterna, girando el volante a tope para ver los delanteros por dentro. :: Sin cortes ni deformaciones. :: Hernias/chichones (estructura rota: peligro de reventón), cortes profundos, grietas por envejecimiento. :: r Reparaciones :: Buscar tarugos o parches en la banda y flancos. :: Sin reparaciones o parche correcto en banda. :: Reparación en el flanco o en el hombro: neumático a reemplazar. :: y Presión :: Manómetro en frío vs. etiqueta del pilar B. :: Dentro de ±10 % de lo recomendado. :: Un neumático muy bajo: pinchazo lento, llanta dañada o válvula defectuosa. :: y Rueda de repuesto y herramientas :: Sacar el repuesto: tipo (completo o temporal), presión, fecha, estado. Gata y llave de ruedas presentes. :: Completo, inflado, fecha razonable. :: Sin repuesto o con repuesto vencido/desinflado; repuesto nuevo y una rueda "usada": se cambió por algo. :: y

Llantas y fijaciones

Golpes y fisuras :: Revisar el labio interior y exterior de cada llanta con linterna. :: Sin deformaciones ni fisuras. :: Llanta doblada (vibra a velocidad), fisura (peligro), soldada o enderezada. :: r Roces de solera :: Rayas en el borde exterior. :: Menores. :: Roces profundos: revisar alineación y neumático en esa rueda. :: y Pernos/tuercas :: Que estén todos, mismo tipo, sin daño en las cabezas; perno de seguridad con su llave. :: Completos y en buen estado. :: Faltan pernos; tuercas dañadas (llave de impacto mal usada); llave de seguridad perdida. :: y Sensores de presión (TPMS) :: Si el auto los trae, verificar testigo apagado en el tablero. :: Sin testigo. :: Testigo encendido o "anulado": sensores dañados (costo por rueda). :: y

Frenos visibles (sin desmontar)

Discos :: Mirar por los rayos de la llanta con linterna: surcos, labio, color azulado, óxido. :: Superficie lisa y pareja. :: Labio marcado, surcos profundos, color azul (sobrecalentamiento). :: y Pastillas :: Mirar espesor por la ventana del cáliper. :: ≥ 3 mm. :: < 3 mm o desgaste en cuña (cáliper agripado). :: y Cálipers y mangueras :: Fugas, mangueras agrietadas o infladas. :: Secos y en buen estado. :: Humedad en el cáliper o manguera: fuga de líquido de frenos. :: k Frenos traseros de tambor :: Ruido al rodar, filtraciones en el interior de la llanta. :: Sin filtraciones. :: Mancha húmeda en el interior de la llanta trasera: cilindro de rueda con fuga. :: r
