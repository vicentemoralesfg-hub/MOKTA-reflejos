Vidrios, ópticas y exterior

Los vidrios y focos tienen fecha y marca: son "testigos" silenciosos de choques, robos y reparaciones.

5–8 minRequiere ayudante para luces
Cómo leer la fecha de un vidrio

En la serigrafía de cada vidrio aparece la marca, normas y un código de fecha (dígito del año y puntos o números que indican el mes, según el fabricante). Todos los vidrios deberían ser de la misma marca y de fechas cercanas a la fabricación del auto. Un parabrisas cambiado es común (piedrazos); una luneta o vidrio lateral de otra marca o fecha sugiere robo, choque o volcamiento.

Vidrios

Parabrisas :: Revisar trizaduras, saltaduras (piedrazos), rayas del limpiaparabrisas y deslaminado en bordes. Mirar a través desde dentro. :: Sin trizaduras; saltaduras menores fuera del campo visual del conductor. :: Trizadura en campo visual del conductor (rechazo en revisión técnica); saltadura que puede crecer. :: y Marca y fecha de cada vidrio :: Anotar marca y fecha de los 6–8 vidrios en la hoja de campo. :: Misma marca y fechas coherentes. :: Vidrio lateral o luneta de otra marca/fecha: averiguar causa (choque, robo). :: y Grabado de patente :: Patente grabada en todos los vidrios y espejos. :: Coincide con la placa. :: Falta en uno (reemplazado) o no coincide. :: r Sellos y gomas de vidrios :: Mirar el cordón de uretano del parabrisas y luneta; gomas sin grietas. :: Sello uniforme, sin filtraciones. :: Uretano irregular o desbordado (instalación deficiente → filtraciones y ruido). :: y Alzavidrios (prueba exterior) :: Bajar y subir cada vidrio completo; mirar alineación al cerrar puerta. :: Suben y bajan parejos y sellan arriba. :: Vidrio que baja torcido, lento o queda separado de la goma. :: y Láminas de control solar :: Revisar estado (burbujas, decoloración) y si hay lámina en parabrisas o vidrios delanteros. :: Ausentes o en buen estado y permitidas. :: Láminas en vidrios donde no están permitidas: costo de retiro y observación en revisión técnica. :: y

Ópticas y luces

Focos delanteros (carcasa) :: Revisar opacidad, rayas, fisuras, condensación interior, fijaciones rotas y fecha/marca en la carcasa. :: Transparentes, secos, de la marca original. :: Un foco nuevo y otro viejo (choque); condensación (sello roto); patas de fijación rotas o pegadas. :: y Funcionamiento de luces :: Con ayudante: posición, baja, alta, neblineros, intermitentes, emergencia, freno (incluida 3ª luz), retroceso, patente, luces diurnas. :: Todas funcionan, mismo tono de color. :: Luces quemadas, tono distinto (xenón/LED aftermarket), intermitente rápido (ampolleta quemada). :: y Regulación de altura / faros adaptativos :: Si tiene: mover la regulación y observar; en faros direccionales, girar el volante. :: Responden correctamente. :: Testigo de falla de iluminación o módulo de faros que no responde (costoso). :: y Focos traseros :: Fisuras, humedad, cinta adhesiva, fijaciones. :: Intactos y secos. :: Agua dentro del foco; fisuras selladas con silicona. :: y

Elementos exteriores

Espejos laterales :: Ajuste eléctrico, abatimiento, calefacción, intermitente integrado, carcasa. :: Funcionan todas las funciones. :: Carcasa reemplazada (otro color), motor que no responde. :: y Limpiaparabrisas y lavador :: Probar velocidades, intermitente, sensor de lluvia, lavador delantero y trasero. :: Barren limpio, sin saltos. :: Plumillas que rayan, motor débil, sin lavador. :: y Chapas y manillas :: Abrir cada puerta por fuera y por dentro; chapa con llave. :: Todas funcionan. :: Chapas forzadas (marcas alrededor del cilindro) o manillas que no abren. :: y Maleta / portalón :: Apertura (llave, botón, mando), amortiguadores a gas, cierre eléctrico si tiene, gomas. :: Se mantiene abierto solo y cierra bien. :: Amortiguadores vencidos; agua o humedad en la goma. :: y Tapa de combustible / puerto de carga :: Apertura, tapa, olor a combustible alrededor. :: Abre y sella bien. :: Olor a combustible, tapa forzada, puerto de carga dañado (EV). :: y Techo solar / panorámico :: Abrir, cerrar, inclinar, cortina. Revisar drenajes (vertir poco agua si el vendedor lo permite) y manchas en tapiz. :: Funciona suave y sin ruidos; tapiz seco. :: Manchas de agua en tapiz, motor forzado, vidrio que no cierra parejo. :: r Enganche de remolque :: Presencia, desgaste de la bola, conector eléctrico. :: Sin enganche o enganche poco usado. :: Bola muy gastada: uso intensivo de arrastre (embrague, caja y frenos sobreexigidos). :: y Barras de techo y accesorios :: Fijación, perforaciones agregadas al techo, filtraciones. :: De fábrica o bien instalados. :: Perforaciones caseras en el techo con sellador. :: y
